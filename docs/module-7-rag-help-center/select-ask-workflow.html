2. Select-and-Ask Workflow

Overview​

The Select-and-Ask workflow is a powerful feature that allows you to interact with specific content from the documentation by selecting text and asking questions about it. This contextual approach enables more precise and relevant answers from the RAG chatbot.

How Select-and-Ask Works​

Basic Selection Process​

  1. Highlight Text: Select specific text from any documentation page
  2. Context Menu: A context menu will appear with the chatbot option
  3. Ask Question: Ask a question specifically about the selected text
  4. Receive Contextual Answer: Get an answer that references the selected content

Example Workflow​

1. You're reading about ROS 2 launch files
2. You select the code example showing a Node action
3. You ask: "How do I add parameters to this node?"
4. The chatbot provides an answer specifically about adding parameters to the selected node configuration

Advanced Selection Techniques​

Single Line Selection​

  • Use Case: Asking about a specific parameter or configuration
  • Example: Select a single line of launch file code to ask about its purpose
  • Best For: Quick clarifications and definitions

Multi-Line Selection​

  • Use Case: Understanding complex code blocks or configurations
  • Example: Select an entire launch file function to understand its complete functionality
  • Best For: Comprehensive explanations of code sections

Cross-Page Selection​

  • Use Case: Referencing concepts from different chapters
  • Example: Select text from ROS 2 architecture chapter while reading about Isaac Sim integration
  • Best For: Understanding relationships between different concepts

Practical Applications​

Code Understanding​

Selected Text: "Node(
    package='my_package',
    executable='my_node',
    name='my_node_name',
    parameters=[{'param_name': 'param_value'}]
)"

Question: "What other parameters can I set for a Node action?"

Troubleshooting Specific Issues​

Selected Text: "ros2 run package_name executable_name"

Question: "What should I do if this command fails with 'executable not found'?"

Configuration Clarification​

Selected Text: "The robot_state_publisher takes a URDF file and publishes the state of the robot to tf"

Question: "How do I specify the URDF file path in my launch file?"

Integration with Development Environment​

IDE Integration​

Some development environments support similar select-and-ask functionality:

  • VS Code: Extensions that allow selecting code and asking questions
  • PyCharm: Plugins that integrate with documentation systems
  • Custom Solutions: Development of internal tools

Workflow Enhancement​

  • Documentation Reading: Use selection to clarify complex concepts
  • Code Development: Select code snippets to understand or modify
  • Debugging: Select error messages to get specific troubleshooting help

Best Practices for Select-and-Ask​

Effective Selections​

  • Be Precise: Select only the text you want to ask about
  • Include Context: Sometimes include surrounding text for better understanding
  • Complete Units: Select complete sentences or code blocks when possible
  • Avoid Ambiguity: Don't select text that could refer to multiple concepts

Formulating Questions​

  • Reference Selection: Start questions with "What does this mean?" or "How does this work?"
  • Be Specific: Ask about specific aspects of the selected text
  • Request Examples: Ask for practical examples based on the selection
  • Seek Clarification: Ask for simpler explanations if the concept is complex

Advanced Features​

Multi-Modal Selection​

  • Text + Images: Select text near diagrams or images for combined context
  • Code + Comments: Select both code and explanatory comments
  • Cross-Reference: Reference selections from different parts of the documentation

Chained Selections​

  • Follow-up Questions: Ask additional questions about chatbot responses
  • Refinement: Use chatbot responses as new selection targets
  • Deep Dives: Explore topics in increasing depth through chained selections

Troubleshooting Selection Issues​

Selection Not Working​

  • Browser Compatibility: Ensure you're using a supported browser
  • JavaScript Enabled: Make sure JavaScript is enabled
  • Ad Blockers: Disable ad blockers that might interfere with the feature
  • Cache Issues: Clear browser cache if the feature stops working

Context Loss​

  • Long Selections: Very long selections might lose context
  • Complex Formatting: Highly formatted text might not be properly captured
  • Dynamic Content: Some dynamically loaded content might not be selectable

Examples of Effective Select-and-Ask Usage​

Learning New Concepts​

Selected: "The ROS 2 graph represents the network of nodes and their communication relationships"
Question: "Can you explain how nodes discover each other in the ROS 2 graph?"
Answer: Detailed explanation of node discovery mechanisms

Code Implementation​

Selected: "from launch import LaunchDescription\nfrom launch_ros.actions import Node"
Question: "What other actions are available in launch_ros.actions?"
Answer: List of available actions with brief descriptions

Configuration Problems​

Selected: "robot_state_publisher and joint_state_publisher"
Question: "How do these two nodes work together in my robot setup?"
Answer: Explanation of the relationship and configuration requirements

Integration with Development Process​

During Learning Phase​

  • Use selection to clarify complex concepts
  • Ask for additional examples of unclear topics
  • Get immediate feedback on understanding

During Implementation​

  • Select configuration examples when implementing
  • Ask for modifications to existing examples
  • Get troubleshooting help for specific code sections

During Debugging​

  • Select error messages for explanation
  • Ask about specific configuration issues
  • Get suggestions for diagnostic steps

Summary​

The Select-and-Ask workflow provides a powerful way to get contextual help by selecting specific content from the documentation. This feature enables more precise and relevant answers from the RAG chatbot, making it easier to understand complex concepts and implement specific features. By mastering this workflow, you can significantly enhance your learning and development efficiency when working with humanoid robotics systems.
